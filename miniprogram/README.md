# 单词突击007 - 微信小程序

> 本文件夹包含微信小程序源代码，是独立项目。

## 📱 开发指南

### 环境要求
- 微信开发者工具
- AppID（从微信公众平台获取）

### 开发步骤
1. 打开微信开发者工具
2. 导入项目：选择 \miniprogram/\ 文件夹
3. 填写 AppID
4. 开始开发

## 🚀 部署

1. 在微信开发者工具中点击「上传」
2. 登录微信公众平台提交审核
3. 审核通过后发布
